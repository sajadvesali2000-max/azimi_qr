# azimi_qr

این مخزن یک صفحه HTML شخصی (کارت ویزیت دیجیتال) دارد که در پوشه `docs` قرار گرفته تا با GitHub Pages منتشر شود.

اگر می‌خواهید وقتی کسی روی لینک مخزن کلیک می‌کند مستقیماً صفحهٔ HTML نمایش داده شود، لطفاً مراحل زیر را انجام دهید (نیازمند فعال‌سازی GitHub Pages در تنظیمات مخزن):

1. به Settings → Pages در مخزن بروید.
2. بخش "Source" را روی branch `main` (یا شاخهٔ پیش‌فرض شما) تنظیم کنید و پوشه را `docs` انتخاب کنید.
3. Save را بزنید و چند دقیقه صبر کنید تا صفحه منتشر شود.

پس از انتشار، آدرس صفحه این خواهد بود:

https://sajadvesali2000-max.github.io/azimi_qr/

توضیحات اعمال شده توسط Copilot:
- فایل `docs/index.html` اضافه/به‌روز شد و تصویر QR در آن به صورت درون‌خطی (SVG) قرار گرفت تا نیاز به فایل خارجی نباشد.
- شماره کارت در صفحه وجود دارد؛ اگر مایلید آن را ماسک یا حذف کنم بگویید تا امن‌ترش کنم.
- README این مخزن حاوی همین دستورالعمل‌ها و لینک صفحه است.

توجه: به‌دلیل محدودیت‌های دسترسی GitHub، ریدایرکت خودکار از صفحه‌ی اصلی مخزن (github.com/owner/repo) به صفحه‌ی GitHub Pages قابل انجام نیست. بهترین راه این است که لینک GitHub Pages را به مخاطبان بدهید یا در README یک لینک برجسته قرار دهید (که من اضافه کردم).
